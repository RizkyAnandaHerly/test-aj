# Warehouse Monitoring System

Aplikasi Monitoring Pergerakan Barang dalam Sistem Pergudangan Berbasis Web.

## Tech Stack
- Backend: Laravel 11 (Monolith + Blade)
- Database: MySQL
- Auth: Laravel Breeze / Session

## Setup Lokal
1. Clone repo ini
2. `composer install`
3. Copy `.env.example` → `.env`, isi DB credentials
4. `php artisan key:generate`
5. `php artisan migrate`
6. `php artisan serve`
